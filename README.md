## Run Locally

Each project is self-contained and has its own dependencies.

```powershell
npm install
npm run dev
```

The root command starts Study Hall. Open a separate terminal at the repository root for each other app:

```powershell
cd .\quiz-arena
npm install
npm run dev
```

```powershell
cd .\collaborative-kanban
npm install
npm run dev
```

See each project README for its tests, build commands, and current limitations. These projects are not publicly deployed yet; local dev URLs are not public demos.
